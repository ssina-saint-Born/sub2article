## Phase 1, Task 4 — Export to .docx and .pdf for Book-to-Digital

### Overview

Wire the "Finish Book Processing" (پایان پردازش کتاب) button to open a dark-themed **Export Options** modal that offers two working downloads (Word `.docx` and PDF), fed by `accumulatedText` from `useBook()`. ### Step-by-Step

#### 2. Create `src/utils/exportUtils.js`

Shared helper + two export functions. Each:
- Generates the binary blob in-memory
- Triggers a browser blob download (works in Electron renderer + plain browser)
- Returns `{ ok, path?, error? }` — mirrors the shape used by `ocrEngine.js` so callers can log uniformly
- **Preserves all line breaks**: DOCX uses one `Paragraph` per line (so `\n\n` becomes two blank-line paragraphs), PDF calls `splitTextToSize` per line so the `\n\n` blank line is honored with an empty-page-feed
- **Persian/RTL**: PDF uses a Unicode TTF font is too heavy to bundle for Task 4 — instead the PDF uses the built-in Roboto/standard font with `splitTextToSize` (Persian glyphs still render; advanced RTL shaping is acceptable best-effort for this phase, explicit follow-up left for Phase 2). DOCX sets both paragraphs to RTL direction auto-detected from the first non-empty line.

```js
// src/utils/exportUtils.js
export async function exportToDocx(text, opts = {}) { ... }
export async function exportToPdf(text, opts = {}) { ... }
// internal: triggerBlobDownload(blob, filename)
// internal: detectIsRtl(text) → boolean
```

- DOCX: `new Document({ sections: [{ properties: { ... }, children: <Paragraph[]> }] })`, each `new Paragraph({ text: line, bidirectional: isRtl })`. Empty lines → `new Paragraph({ text: '' })`. Returns Blob via `Packer.toBlob(doc)` from the `docx` library.
- PDF: `new jsPDF({ unit: 'pt', format: 'a4' })`, set font + size, `splitTextToSize(line, maxWidth)` per line, manual Y-cursor with `addPage()` on overflow, RTL-friendly left margin.
- Lazy `await import('docx')` / `await import('jspdf')` so cost is paid only when the user actually exports (matches the dynamic-import pattern already used in `ocrEngine.js`).

#### 3. Add the modal + wiring to `BookProcessor.jsx`

**State added (local, UI-only — does NOT touch context):**
```js
const [exportModalOpen, setExportModalOpen] = useState(false);
const [exporting, setExporting] = useState(null); // 'docx' | 'pdf' | null
```

**Rewrite `handleFinishBook`:**
```js
const handleFinishBook = useCallback(() => {
  if (!accumulatedText) return;
  setExportModalOpen(true);
}, [accumulatedText]);
```

**New `handleExport(format)` callback** (wired to the modal's two buttons):
```js
const handleExport = useCallback(async (format) => {
  if (!accumulatedText) return;
  setExporting(format);
  try {
    const result = format === 'docx'
      ? await exportToDocx(accumulatedText, { filename: 'subscribe-book-export.docx' })
      : await exportToPdf(accumulatedText, { filename: 'subscribe-book-export.pdf' });
    if (result.ok) addLog('success', `Exported as ${format.toUpperCase()}.`);
    else addLog('error', `Export failed: ${result.error}`);
  } catch (err) {
    addLog('error', `Export error: ${err.message}`);
  } finally {
    setExporting(null);
  }
}, [accumulatedText, addLog]);
```

**`ExportOptionsModal` — inline component** (defined at the bottom of the file, near `StatChip`):

- **Dark theme** matching the app: `bg-surface-900/90 backdrop-blur-md`, panel `bg-surface-900 border border-surface-700/60 rounded-2xl glow-lg`
- **Title bar**: "Export Options" + close ✕
- **Section A — File Downloads**: two large buttons side-by-side:
  - "Download as Word (DOCX)" → `handleExport('docx')` with `disabled={exporting!=='docx' || null}` and a spinner when `exporting==='docx'`
  - "Download as PDF" → `handleExport('pdf')` same pattern
- **Section B — Generate AI Dataset (Phase 2)**: two disabled, greyed placeholders ("QA Pairs" / "Training Corpus") with a "Coming soon in Phase 2" chip — leaves the visual room the task asked for, but does nothing yet
- **Footer**: word/char count from `accumulatedText` so the user sees what will be exported
- Closes on backdrop click, ✕, or Esc key

Modal is rendered as the last child inside the outermost `<div>` of `BookProcessor.jsx`, guarded by `{exportModalOpen && (...)}`, so it overlays only when open.
