2. Read `const { providerUrl, apiKey, modelName } = settings;`; if `!apiKey || !providerUrl`, `addLog('error', 'API Key or Base URL is missing…')` and return (same wording SubtitleProcessor uses).

8. Pass to `ExportOptionsModal` so it can disable its close button while a generation is in-flight.

### Step 3 — Clean, export, download

Inline clean function (kept small and inside BookProcessor module scope, not exported):
```js
function sanitizeDatasetJSON(raw) {
  let s = (raw || '').trim();
  // Strip accidental ```json ... ``` fences the model may add despite instructions.
  s = s.replace(/^```(?:json|JSON)?\s*/i, '').replace(/\s*```$/,'');
  // If there's still a stray opening fence mid-stream, strip it.
  s = s.replace(/```/g, '');
  // Find the outermost JSON array/object — tolerate leading/trailing prose.
  const start = s.search(/[\[{]/);
  const end = Math.max(s.lastIndexOf(']'), s.lastIndexOf('}'));
  if (start !== -1 && end !== -1 && end > start) {
    s = s.slice(start, end + 1);
  }
  return s.trim();
}
```
Steps inside `handleGenerateDataset` after the `callLLM` result:
- If `!result.ok` → `addLog('error', \`Dataset generation failed: ${result.error}\`)` and return.
- `const cleaned = sanitizeDatasetJSON(result.text);`
- **Validate**: `JSON.parse(cleaned)` in a try/catch. If it parses, pretty-print with `JSON.stringify(parsed, null, 2)`. On parse failure, log `addLog('warning', 'AI returned non-JSON output; saving raw text for inspection.')` and fall back to the cleaned string as plain text (`text/plain` Blob, `.txt`) so the user still gets their data; surface the issue.
- **_blob**: `new Blob([output], { type: isJSON ? 'application/json' : 'text/plain' })`.
- **Download**: `const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = \`dataset-${type}-${Date.now()}${isJSON?'.json':'.txt'}\`; document.body.appendChild(a); a.click(); a.remove(); setTimeout(()=>URL.revokeObjectURL(url), 1000);`
